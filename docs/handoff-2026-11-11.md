## 2. Maintainer rulings

These came from the maintainer during the sprint. They outrank derivations and measurements, and
they are the part of the context that the code alone does not show.

1. **Lowest crossover phase.** Zero phase is the default, as shipped in 0.1.0-beta. The maintainer
   blind-tested minimum phase against zero phase before 0.1.0 and repeatedly picked what shipped.
   Minimum phase (Linkwitz-Riley) exists only as the opt-in `--xover-phase minimum`. Do not change
   this default on the strength of pre-ring measurements or theory. The final audit also measured
   that the minimum-phase band sum raises true peak by 1.6 to 5.8 dB on clipped, low-crest
   material (audit report 3.11).
2. **Sound-affecting defaults.** Propose a change to any default that alters the sound as a
   toggle, and ask first. The maintainer's listening tests decide.
3. **Live profile calibration.** The proposal in `docs/audit-2026-11-10/live.md` B.4 was approved
   as written ("that's fine for live material") and is applied: target −11.5 dBFS on the engine's
   meter, no clipper under the auto character, the sustained-material rule, the conditional side
   strip, EQ bounds of ±1 dB. It is still calibrated on synthetic fixtures and published
   statistics; see section 4.
4. **Master ceiling.** −0.3 dBTP for the default master is the maintainer's ruling. The delivery
   check is amber only for `--streaming` and `--cd` deliveries.
5. **Which documents rule.** `docs/gain-staging.md` is the ruling document; its sections 16 to 20
   supersede earlier ones. `docs/spec-draft.md` is a historical draft with a status block listing
   where it has been superseded.
6. **The first concern named.** Audio-rate (per-sample) parameter automation was an audible
   defect in earlier versions. Any change to a dynamics stage should be followed by a run of
   `tools/audio_rate/` (its README says how).
7. **Audio is never committed.** Premasters, renders and analyses of them are private. `.gitignore`
   excludes audio of every kind, `work/`, `fixtures/premasters/` and `premaster corpus/`.
8. **Intent.** The project is meant as an open-source gift to the creative community. The
   maintainer asked for care on correctness, DSP hygiene and UI/UX, for stem and stereo mastering
   of both electronic and live material, with feedback that references current standards.

## 3. Working on it from a fresh clone

- **Python 3.12 is required.** With uv: `uv venv --python 3.12`, then install from the lock file
  for the platform in `requirements/` (`requirements/README.md` has the uv route). A uv-made venv
  has no `pip` module: use `uv pip` and `uv build`, and note that `npm run engine` expects pip.
- **Tests.**
  - fast tier, about 10 minutes: `python -m pytest -m "not slow" -q -p no:cacheprovider`
  - slow tier, about 30 minutes: `python -m pytest -m slow -q -p no:cacheprovider`
  - desktop shell, from `desktop/src-tauri`: `cargo test --locked` and
    `cargo clippy --all-targets -- -D warnings`
- **Real-material tests skip** unless `fixtures/premasters/manifest.toml` points at premasters
  (`manifest.example.toml` shows the format). The EBU loudness set is not redistributable and
  lives in the ignored `fixtures/ebu/`; without it the EBU cases skip.
- **A numba cache crash seen once.** `tests/test_planner_fixes.py`, run as a whole file, crashed
  with an access violation in numba's `localmax` (called from librosa's `beat_track`). It passes
  with `NUMBA_CACHE_DIR` pointed at an empty directory. It looked like a stale cache in that one
  environment; a fresh environment has not shown it.
- **Line endings.** `.gitattributes` sets LF for text. If a merge reports a whole-file conflict,
  retry with `-X ignore-space-at-eol`.
- **Build outputs are large and ignored.** `desktop/src-tauri/target/` reaches about 5 GB per
  checkout; `cargo clean` there is safe at any time.
- **The `agy` auditor** named in `mastering-engine-brief.md` was not available during the sprint;
  the audits were done by Claude agents instead.
- **Publishing.** The public history is authored under the project's GitHub noreply identity. On
  a new machine, compare `git log -1 --format="%an <%ae>"` for your commits with `origin/main`
  before pushing, and set `user.name` and `user.email` in the clone to match.

## 4. Open items

None of these blocks use. Each is recorded in the audit report at the place named.

1. **No real premaster was measured in the sprint.** Every number in the reports comes from
   synthetic signals. The maintainer provided a premaster corpus late in the sprint, but the final
   audit did not run on it. The first thing worth doing next: point
   `fixtures/premasters/manifest.toml` at real premasters, run the real-material tests, and listen
   to the changes that alter the sound (items 2 to 4 below).
2. **Live target.** −11.5 dBFS (about −14.5 LUFS integrated on band material) against −13 (the
   AES TD1008 value). The calibration needs the maintainer's own live masters measured on
   `meter.rms_meter` (report section 4 item 2, `live.md` D.2).
3. **Glue attack floor of 3 ms.** It removes the only wideband splatter in the chain; listen on a
   kick-heavy track (section 4 item 3). The glue's steady-sub distortion remains (aggressive
   preset at 30 Hz, about −38.8 dB THD; report 3.1).
4. **Limiter hold of 25 ms.** It removes sub ripple and delays the start of release by 25 ms
   (section 4 item 4).
5. **Base-rate re-limit.** It still touches most samples by a small amount rather than only the
   excess (report 3.1, planner-solver S4-6).
6. **Resonance recall on line-spectrum-dense material is low**, and was before the sprint: one of
   eight injected resonances found on the dense loop (report 3.11).
7. **Live report, small points** (report 3.11): the loudness sanity range assumes the default
   target; the `notches_tonal` flag can no longer fire; the input EQ steps between Tilt 0 and
   Tilt 0.1; the UI's "Side" handle shows 100 Hz when a master has no side strip.
8. **Not applied from the live audit:** A4 (the mid/side link applies more side reduction than the
   budget table reports; `live.md` D.8), A6 (`grid_informative` for every profile), A9, A11, A13,
   and the auto character still quoting a detected tempo on sustained material (A14).
9. **Questions for the maintainer** that are still open: delivery flag policy, the kick-mask ramp,
   the musical-guard pitch-class rules, and the stem-mastering design notes (report section 4,
   items 5 to 8).
10. **Source comments cite documents that are not in the public tree** (`audit/brief-*.md`,
    `work/...`, older review documents). `docs/audit-2026-11-10/hygiene.md` F15 lists the places.
11. **The remote branch `macos-linux-installers`** was squash-merged into `main` as `fb082d1`
    before the sprint; what remains on it is two older documents. It can be deleted.
